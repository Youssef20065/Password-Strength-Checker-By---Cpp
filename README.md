# Password-Strength-Checker-V 1.0-

**Version:** 1.0.0

Password-Strength-Checker is a simple C++ console application that checks password strength based on five criteria.

## Features

- Checks password length.
- Detects uppercase letters.
- Detects lowercase letters.
- Detects numbers.
- Detects special characters.
- Calculates a password score out of 5.
- Displays a password strength rating.

## Scoring System

| Score | Strength |
|---|---|
| 0–1 | Very Weak |
| 2 | Weak |
| 3 | Moderate |
| 4 | Strong |
| 5 | Very Strong |

## Requirements

- A C++ compiler, such as g++.
- Windows, Linux, or another environment that supports your compiler.

## How to Compile

Open a terminal in the project directory and run:

```bash
g++ main.cpp -o Password-Strength-Checker.exe
```

## How to Run on Windows

    powershell
.\Password-Strength-Checker.exe


## Purpose

This project was created to practise C++ fundamentals, including functions, loops, strings, conditions, and basic problem-solving.

**Note:** This is a beginner educational project, not a complete password-security assessment.
